# TETRAform SEO Keyword Sources & Confidence Report

This document outlines the sources used to identify target keywords for TETRAform and the degree of confidence associated with each category. This data supports the SEO audit and landing page optimization strategy.

## 1. Data Sources

The keywords identified for TETRAform (as documented in `docs/LANDING-PAGE.md`) were derived from the following sources:

### A. Competitor Benchmarking
We analyzed the Chrome Web Store listings and landing pages of established competitors in the "form filler" category to identify high-volume search terms.
- **Competitors Analyzed:** Lightning Autofill, AutoFill Forms, SimpleFill.
- **Data Extracted:** Title tags, short descriptions, and recurring utility-based phrases.

### B. Persona-Based Intent Mapping
Search terms were hypothesized based on the specific pain points of our target user segments.
- **Personas:** Job Seekers, Students (Scholarships/Internships), Freelancers/Consultants, and Sales/Business Reps.
- **Intent:** Phrases like "autofill job applications" or "CRM autofill" were selected based on the specific forms these users interact with most frequently.

### C. Chrome Web Store ASO (App Store Optimization) Trends
Reviewing the "Productivity" category on the Chrome Web Store to identify broad category terms that drive organic discovery.
- **Core Terms:** "Form autofill", "autofill extension", "automatic form filler".

---

## 2. Confidence Levels

The following confidence levels indicate the estimated accuracy and relevance of these keywords for driving traffic to TETRAform.

| Keyword Category | Confidence | Rationale |
| :--- | :--- | :--- |
| **Primary Utility Keywords** (e.g., *form autofill*, *form filler*) | **High (95%)** | These are the industry-standard terms for the product category. They have high search volume and direct intent. |
| **Long-Tail Persona Keywords** (e.g., *job application autofill*) | **Medium-High (80%)** | Based on logical user pain points. While volume is lower than primary terms, conversion intent is significantly higher for these niches. |
| **Platform-Specific Keywords** (e.g., *autofill Chrome extension*) | **High (90%)** | Validated by Chrome Web Store category naming conventions and common user search patterns for browser add-ons. |
| **Competitor-Adjacent Keywords** (e.g., *one-click autofill*) | **Medium (70%)** | These terms focus on specific features that distinguish us from competitors like Lightning Autofill. |

---

## 3. Methodology Notes
This keyword data was compiled through qualitative analysis of the competitive landscape and user persona research. No paid SEO tools (e.g., Ahrefs, Semrush) were used for this initial audit; data is based on organic marketplace observation and target market needs analysis.
